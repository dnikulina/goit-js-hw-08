## Overview

This repository contains an interactive image gallery built with JavaScript from a predefined image dataset.

The project focuses on dynamic gallery generation and user interaction with preview and full-size image versions.

## Tech Stack

- JavaScript
- HTML
- CSS
- DOM API
- Git & GitHub

## Functionality

- stores image metadata in a structured JavaScript array;
- dynamically renders gallery items;
- uses preview and original image URLs;
- provides descriptive alternative text for images;
- separates gallery logic into a dedicated JavaScript module.
